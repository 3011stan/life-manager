# Life Manager web app (cloud-stanos)

This repository holds the Next.js web app and all product documents. The API
lives in `../life-manager-backend` (its own `AGENTS.md`).

## Where things are

- Workflow: `docs/development-flow.md`. Invariants: `.specify/memory/constitution.md`.
- Feature specs: `specs/NNN-*/` (spec, plan, research, data model, contracts, tasks).
- Architecture decisions: `docs/adr/`.
- API client: generated by orval from the pinned `openapi/openapi.json` into
  `src/lib/api/generated/`. Never edit generated files; copy the backend's
  `openapi.json` and run `npm run api:generate`.
- Every API call goes through `src/lib/api/mutator.ts` (credentials, time zone
  header, idempotency key, read-only offline guard).

## Commands

| Command | Does |
|---|---|
| `npm run check` | lint + type checks (app and service worker) |
| `npm test` | Vitest unit tests |
| `npm run e2e` | Playwright, desktop and 390×844 projects; needs the API on :4000 |
| `npm run api:check` | fails when the generated client is out of date |

## Rules

- Test first for behavior changes; a bug gets a failing regression test before the fix.
- Mobile at 390 px: no horizontal scroll, touch targets at least 44 px.
- Offline is read-only: writes must fail visibly, never queue silently.
- No secrets, personal data, or Obsidian vault content in the repository or fixtures.
- Commits carry no AI co-author trailer.
